# Ситуационный центр EXIM

Прототип веб-платформы «Информационно-аналитическая система ситуационного центра банка в части EXIM».

Цель прототипа — показать, как банк может централизованно мониторить экспортно-импортный портфель, клиентов, продукты, страны, маршруты, цепочки поставок, риски, прогнозы, качество данных и управленческие решения.

Система демонстрирует принцип: это не просто дашборд, а инструмент поддержки решений. Платформа показывает, что произошло, почему это важно, что может произойти дальше, какое действие рекомендуется, кто должен реагировать и зафиксировано ли решение.

## Как запустить

В окружении Codex используется локальный Node.js runtime. Если `node` и `pnpm` доступны в системе, достаточно:

```bash
pnpm install
pnpm dev
```

В текущем окружении проверенный запуск:

```bash
PATH="/Users/memodlike/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin:$PATH" \
  /Users/memodlike/.cache/codex-runtimes/codex-primary-runtime/dependencies/bin/pnpm dev
```

Production-сборка:

```bash
PATH="/Users/memodlike/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin:$PATH" \
  /Users/memodlike/.cache/codex-runtimes/codex-primary-runtime/dependencies/bin/pnpm build
```

## Архитектура

- React + TypeScript + Vite.
- Адаптивный интерфейс без внешних платных сервисов.
- SVG/CSS-диаграммы вместо зависимости от внешнего BI.
- Мок-данные вынесены в `src/data/mockData.ts`.
- Типы доменной модели описаны в `src/types.ts`.
- Повторно используемые UI-компоненты находятся в `src/components`.
- Основные продуктовые разделы находятся в `src/sections/Sections.tsx`.

## Безопасность и контроль

Даже в прототипе отражены важные правила промышленного решения:

- рекомендации ИИ являются консультативными;
- критические действия требуют проверки человеком;
- каждое событие риска имеет владельца;
- каждое принятое действие фиксируется в журнале решений;
- качество данных отображается явно;
- предусмотрены роли, матрица доступа и аудит;
- перед промышленным запуском обязательны проверка информационной безопасности, тестирование и передача в IT support.

Прототип можно подключить к реальным источникам банка:

- DWH;
- CRM;
- банковские операции;
- платежи;
- продуктовые системы;
- KPI RM;
- ODEPT;
- риск-системы;
- BI layer;
- внешние API;
- государственные, налоговые, таможенные, логистические, рыночные и партнёрские источники.

Для промышленного решения потребуется слой авторизации, управление доступами, интеграционные контракты, журналирование, контроль качества данных, мониторинг SLA, контур информационной безопасности и согласованная методология KPI.

## Допущения

- Все значения портфеля, доходности, рисков, клиентов и прогнозов условные.
- Период реализации проекта принят как июль 2026 — июль 2027.
- PERT-оценка и дорожная карта соответствуют условиям задания.
