# Информационно-аналитическая система Ситуационного центра EXIM банка

Данный проект представляет собой высокотехнологичный, высокоплотный интерактивный исполнительный дашборд (Situal Center) уровня Bloomberg для мониторинга экспортно-импортного портфеля, клиентов, рисков, цепочек поставок, прогнозов и качества интеграционных данных банка.

Интерфейс спроектирован по канонам визуального стиля Apple и Bloomberg Terminal:
* Строгая финансовая палитра с автоматической адаптацией под системную светлую/темную тему и ручным переключателем в шапке.
* Адаптивная верстка от небольших мобильных устройств (320px) до ультрашироких мониторов (2560px+).
* Полноценная имитация реального времени (Live-симуляция) со счетчиками SLA, колебаниями метрик и генерацией комплаенс-событий.

---

## Основные разделы Ситуационного центра

1. **Пульс EXIM** — оперативный дашборд руководителя: сводка за последние 15 минут, интерактивные карточки KPI (портфель, клиенты, SLA, качество данных), графики прогнозов и лента оповещений.
2. **Портфель** — утилизация лимитов финансирования продуктов (кредитование, аккредитивы, гарантии, факторинг) и реестр недавних валютных транзакций.
3. **Клиенты** — база портфельных компаний (крупный/средний бизнес, сегменты, скоринг контрагента, ответственные RM) с глубокой фильтрацией и карточкой-детализацией.
4. **Страны и пути** — страновые риски, объемы экспозиции на страны-партнеры, здоровье транспортных коридоров и задержки на таможенных постах (Достык, Хоргос, Актау).
5. **Цепочки поставок** — интерактивное моделирование 5-этапного логистического коридора (сырье, производство, дистрибуция, опт, контрактный расчет) с выявлением узких мест.
6. **Риски и события** — интерактивная матрица рисков 5x3 (вероятность против влияния) и контроль SLA реакции риск-менеджмента по инцидентам.
7. **Прогнозы (What-If)** — симуляция стресс-сценариев (девальвация валюты, пошлины ЕС, закрытие границ) и сопоставление влияния на доходность.
8. **Рекомендации ИИ** — генеративный советник с оценкой уровня уверенности, финансового эффекта и кнопками принятия/отклонения мер.
9. **Решения** — журнал принятых управленческих директив, назначений ответственных и полный аудит изменений.
10. **Качество данных** — статус интеграции DWH, CRM, Core Banking, KASE API, проверка свежести данных и SLA резервных каналов.
11. **Администрирование** — пульт управления симулятором событий (пауза, ускорение, сброс, ручная вставка риска) и матрица ролевого доступа.

## Симуляция реального времени (Live Stream)
В системе реализован клиентский движок симуляции:
* **Fluctuation**: Каждые 3 секунды показатели объемов продуктов колеблются в пределах ±0.05% для реалистичного движения цифр.
* **SLA Countdown**: Риски имеют таймеры SLA реакции, которые ежесекундно уменьшаются. При исчерпании времени запускается процедура эскалации.
* **Live Alerts**: Периодически в левом углу генерируются новые операционные оповещения, которые можно «пометить просмотренными».
* **Управление**: Через вкладку **Администрирование** можно временно приостановить симуляцию, ускорить ее до 10 раз, принудительно внедрить критический комплаенс-риск или сбросить весь набор данных.

## Быстрые действия и Командная строка (Cmd+K)
Нажатие клавиш **`Ctrl + K`** или **`Cmd + K`** (либо кнопка в шапке) открывает глобальную командную строку:
* Быстрый поиск клиентов (например, «КазМеталл»), событий рисков или продуктов.
* Выполнение системных действий (переключение темы, сброс демо-данных, генерация рисков).

## Запуск проекта

### Требования
* Рекомендуется использовать среду выполнения [Bun](https://bun.sh) (установлена в рабочей зоне) для максимальной скорости установки и сборки.

### Установка зависимостей
```bash
bun install
```

### Запуск сервера разработки
```bash
bun run dev
```
После запуска откройте локальный адрес, выведенный в консоль (обычно `http://localhost:5173`).

### Проверка типов и Сборка продакшн-версии
```bash
bun run build
```

## Дисклеймер
> [!IMPORTANT]
> **Демонстрационный режим**: Все данные компаний (ТОО КазМеталл Экспорт, АО AgroTrade, ТОО QazChem и др.), финансовые метрики, валютные операции, риски и рекомендации ИИ в системе являются полностью вымышленными (генеративными). Система работает локально на стороне браузера (LocalStorage) и не передает данные на внешние сервера.
